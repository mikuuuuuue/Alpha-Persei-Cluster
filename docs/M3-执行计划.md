## 通用方法与验收门

**四步法（每个玩法任务相同）**：

1. **真机走查登记**：本地服（`--res-version 321`，按《M1-真机走查清单.md》§1 环境重建）真机执行该任务走查清单；每条故障按登记簿格式记入 `M3-故障登记簿.md`：

   ```
   | 编号 | 场景 | 操作 | 期望（抓包依据） | 实际 | 涉及 cmd | 涉及模块 | 差分结论 | 状态 |
   ```

   [决策：登记簿格式，沿用 M2.3 登记簿设计]。无故障也记录"走查通过"行（走查清单编号引用）。
2. **差分定位**：官方参照 = `$CAP` rebuilt JSONL 下行帧；本地侧 = 无头重放（`core.dispatch`）或真机本地抓包。**差分口径 [决策，依据实施计划 M3 章通用验收]**：`result` 字段必查；列表型字段比长度与逐元素关键 id；数值字段比量级与方向；帧序列比 cmd 集合（含出帧顺序约束的玩法另注明）；不要求逐字节一致。
3. **TDD 修复**：先在 `tests/m3_<feature>_check.py` 写失败测试（复现差分缺口），跑红 → 修服务代码 → 跑绿 → commit。测试一律跑临时库副本（M1 整改先例：直接写真实库会污染账号数据）。
4. **复测 + 回归**：无头差分复测 + 真机走查清单全过 + M2 冒烟基线不回归（`python tests/smoke_dispatch.py`，M2 产出）。

# -*- coding: utf-8 -*-
"""tests/m3_common.py — M3 玩法测试共用骨架（Task 1 产出，Task 2/4/5/8 消费）

仅测试辅助（临时库 + dispatch 便捷封装），非 M2 回放/冒烟基建 [决策 严格分离]。
模式沿用 tests/m1_dispatch_check.py：跑 account.db 临时副本，禁止写真实库。
"""
import glob
import json, os, shutil, sys

REPO_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
V5_DIR = os.path.join(REPO_ROOT, "v5_server")
if V5_DIR not in sys.path:
    sys.path.insert(0, V5_DIR)

from account_db import get_db            # noqa: E402
import core as core_mod                  # noqa: E402
import operations                         # noqa: E402  (注册副作用)
import generator as _gen                 # noqa: E402
import logger                            # noqa: E402
from codec import encode as _enc, decode as _dec  # noqa: E402

CAP = os.path.join(REPO_ROOT, "Alpha-Persei-Captures")


def make_core(workdir_name):
    """在 account.db 临时副本上构造 (db, core)。workdir_name 形如 'm3_rogueteam_db'。"""
    workdir = os.path.join(REPO_ROOT, "selftest_tmp", workdir_name)
    os.makedirs(workdir, exist_ok=True)
    tmp_db = os.path.join(workdir, "account.db")
    shutil.copy2(os.path.join(V5_DIR, "account.db"), tmp_db)
    db = get_db(tmp_db)
    core = core_mod.Core(db=db, generator=_gen, codec_encode=_enc,
                         codec_decode=_dec, log=logger.log)
    return db, core


def load_up_frames(cap_dirs, family):
    """读各 rebuilt 目录上行帧 JSONL，过滤 family，按 ts 升序。
    文件名不统一（实测 rebuilt1 是 tcp_3_up_8102/tcp_4_up_8105，rebuilt2 是
    tcp_2_up_8105），故 glob 匹配 *up*.jsonl；cap_dirs 必须指向 rebuilt 目录本身，
    批量包的合并目录用 rebuilt/（rebuilt1+rebuilt2 的并集，勿传上层目录以免重复计数）。"""
    frames = []
    for d in cap_dirs:
        for p in sorted(glob.glob(os.path.join(d, "*up*.jsonl"))):
            for line in open(p, encoding="utf-8"):
                f = json.loads(line)
                if f["cmd"] in family:
                    frames.append(f)
    frames.sort(key=lambda f: f["ts"])
    return frames


def frame_sc_list(resp):
    """resp.frames → sc cmd 列表（dict 取 ['sc']，对象取 .cmd，两形态兼容）。"""
    out = []
    for fr in resp.frames:
        out.append(fr["sc"] if isinstance(fr, dict) else fr.cmd)
    return out
